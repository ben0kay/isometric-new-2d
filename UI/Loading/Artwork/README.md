# Loading screen artwork

Drop your own **LoadingBackdrop.png** here.

Recommended: 1920x1080 or higher, landscape 16:9, with important subjects
kept near the middle (the screen center-crops to preserve aspect ratio).
The loading screen automatically loads it at run-time if present.

The location is configured in
`UI/Loading/DefaultLoadingScreenSettings.tres → BackdropPath`.

No PNG is committed with the first pass. Until you supply one, the loading
screen draws its own navy sci-fi background and vector ornamentation.
