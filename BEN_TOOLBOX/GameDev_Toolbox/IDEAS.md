Tool	What you could do yourself
Plant / Tree Creator	Pick a PNG folder, set size, wind, harvesting, and spacing; generate one complete species .tres.
Biome Content Editor	Add or remove species, change spawn weights and density, and see which resources the biome actually uses.
Sprite Viewer	Preview transparency, scale, ground anchor, flipping, and different variants before importing.
Sprite Sheet Splitter	Cut an image into separate sprites using a grid or manually selected rectangles.
Asset Usage Finder	Select a file and see which scenes and resources reference it before moving or deleting it.
Build / Test Launcher	Choose a biome test, build C#, launch Godot, and collect its errors.
Texture Audit	Find oversized images and estimate texture memory, so you can decide what to resize.
Project Health Dashboard	Run resource checks and a build, then show the problems together with a copyable report.
